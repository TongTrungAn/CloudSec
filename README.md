# CloudSec
Đồ án xây dựng hệ thống bảo mật đám mây riêng tối ưu chi phí với 2 phân hệ chính. Thứ nhất, tích hợp mã hóa dữ liệu đầu cuối (AES-256) chống rò rỉ thông tin. Thứ hai, ứng dụng Học sâu (Deep Learning) phát hiện xâm nhập mạng thời gian thực. Sản phẩm tạo ra mô hình cloud khép kín, bảo vệ toàn diện dữ liệu và hạ tầng.
